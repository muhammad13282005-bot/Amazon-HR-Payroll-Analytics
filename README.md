# Amazon HR & Payroll Analytics Dashboard (Power BI)

An interactive Business Intelligence dashboard built to analyze employee compensation, departmental bonus distribution, tax structures, and workforce demographics.

---

## 📊 Project Overview
This project visualizes corporate HR and payroll data to provide key insights into departmental expenses, salary structures, tax allocation, and gender distribution across designations.

---

## 🛠️ Key Metrics & Visualizations Included
1. **Sum of Basic Salary (KPI Card):** Dynamic financial card tracking total basic compensation (e.g., overall portfolio baseline at 622K)[cite: 5].
2. **Sum of Bonus by Department (Pie Chart):** Percentage and monetary breakdown of bonuses across corporate departments (Sales, Operations, IT, HR, Marketing, Finance)[cite: 5].
3. **Sum of Gross Salary by Department (Bar Chart):** Comparative analysis illustrating total gross payroll allocation per department[cite: 5].
4. **Count of Designation by Gender (Bar Chart):** Demographic breakdown of employee designations categorized by gender[cite: 5].
5. **Sum of Tax by Gender (Bar Chart):** Financial visualization tracking tax contributions distributed across gender groups[cite: 5].
6. **Interactive Slicers:** Dynamic name-based and department filters allowing users to isolate individual employee records and view segmented metrics instantly[cite: 5, 6].

---

## 💻 Tech Stack & Tools
* **Data Visualization & BI:** Power BI Desktop
* **SQL: Used for raw data gathering, structuring, and cleaning

## 🎯 How to View / Use
1. Clone or download this repository.
2. Open the `.pbix` file in Power BI Desktop (or review the exported high-resolution dashboard snapshots provided above).
3. Use the slicers to filter data dynamically by employee names and departments.
